# 轮廓布尔运算与数值容差

本服务的并集、相交、差集由 `internal/boolean` 的平面细分（planar subdivision）实现，不依赖外部库。运算发生在文档坐标系，操作数的仿射变换（平移、错切、镜像）先作用于已展平的折线，再按各操作数自己的填充规则（nonzero / evenodd）判定每个平面区域是否属于结果。

## 处理流程

1. 把每个操作数轮廓展平为文档坐标线段，丢弃短于容差的退化边。
2. 两两求交，收集正常交叉、T 接、端点接触与共线重叠的切点。
3. 用空间哈希按容差焊接节点，重建成无向图：重合或在容差内的边合并为同一条图边，这是"重合边不产生碎片"的关键。
4. 以半边（half-edge）结构按角度序枚举平面区域（面）。
5. 正面积面用其内部点的绕向数分类；负面积面（环的外侧）逐半边用法线方向、焊接近距离的探针局部分类，从而正确处理镂空、反向绕向、镜像与窄通道。
6. 两侧分类不同的图边成为结果边界，连接成闭合环，再做共线顶点简化，输出 M/L/Z 轮廓。

## 容差影响哪些设计决策

` tolerance` 是文档坐标系下的距离量，不是相对比例，默认 1e-9，允许范围 1e-12..1。

- **节点焊接**：距离不超过容差的两个顶点视为同一点。容差越大，越多近邻顶点被合并，分段数越少、图形越"干净"，但可能改变本应分开的细节。
- **共线与重合边**：平行且线间距在容差内的边按共线处理，重叠段被焊接，避免重复轮廓和零面积碎片。
- **窄通道**：宽度大于容差的间隙保留为两个独立轮廓（真实通道不被填平）；宽度不超过容差的间隙会被焊接，两侧合并为一个轮廓。是否保留一条窄缝，本质上由"缝宽 vs 容差"决定。
- **退化面积过滤**：面积不超过容差平方的环被视为碎屑丢弃，防止数值噪声生成不可渲染的微小面。
- **共线顶点简化**：偏离邻边不超过容差的中间顶点被移除，输出更短的轮廓，但不跨越真正的拐角。
- **边界稳定性**：外侧探针取焊接近的微小偏移（约 1.5 倍容差），保证落在与边紧邻的区域内，而不会跨过亚容差窄缝。

因此调大容差会提升鲁棒性与简洁度，代价是可能合并接近的特征；调小容差会保留更精细的间隙与顶点，但对输入坐标的数值噪声更敏感。调用方应按画布尺寸与所需最小特征宽度选择容差，并通过同一稿本分别渲染 PNG 与 SVG 核对结果。

## 外观选择

参与形状可能携带不同笔刷，结果只有一个外观，因此由调用方显式选择：

- `first`：使用第一个操作数的笔刷；
- `last`：使用最后一个操作数的笔刷；
- `explicit`：使用请求中显式提供的 brush。

差集以第一个操作数为被减主体，其余操作数依次从中挖去。
